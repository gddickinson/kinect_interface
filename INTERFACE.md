# INTERFACE.md - navigation map

## Capture library
- `kinect_capture.cpp` / `kinect_capture.h` - C++ `KinectCapture` (libfreenect context/device, capture thread,
  depth/RGB callbacks into mutex-guarded buffers, `getFrames`) and its `extern "C"` API.
- `kinect_wrapper.pyx` - Cython `PyKinectCapture` (`init()`, `get_frames()` -> NumPy arrays);
  `kinect_wrapper.cpp` is generated by Cython. `setup.py` - builds the extension (pkg-config / Homebrew / system paths).
- `depth_display.py` - driver-free depth colouring: `normalize_depth`, `colorize_depth`, `jet_lut` (OpenCV).
- `test_kinect.py` - viewer: RGB + colourised depth windows (uses depth_display). `_archive/quickTest.py` - old minimal script.

## Web interface (`web/`)
- `app.py` (FastAPI, `STATIC_ENDPOINTS`), `codebase.py` (repo scanner), `project.py` (text, citations, `/api/jet_lut`,
  `/api/synthetic[/name]`), `synthetic.py` (SYNTHETIC depth frames for the demo/tests).
- `static/`: `depth_engine.js` (+ `.test.mjs`) JS port of depth_display; `demo.js`, `home.js`, `code.js`,
  `highlight.js`, `how.js`, `main.js`, `core.js`, `static_api.js`, styles. `run_web.py` (port 8261).
- `scripts/build_static.py`, `scripts/screenshots.py`, `scripts/make_depth_fixture.py` -> `tests/fixtures/depth_cases.json`.

## Tests
- `tests/test_web.py`; `tests/test_capture_lifecycle.py` compiles `kinect_capture.cpp` with `tests/freenect_stub/`
  (stand-in libfreenect) to test init failure and cleanup.
